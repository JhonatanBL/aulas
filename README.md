# Repositório de Aulas e Projetos Acadêmicos

Este repositório reúne atividades, projetos e materiais de diferentes disciplinas desenvolvidos ao longo da formação acadêmica. A estrutura está organizada por tema, com notebooks, scripts, dados experimentais e implementações em diferentes linguagens.

## Índice

- [Deep Learning](#deep-learning)
- [Estrutura de Dados](#estrutura-de-dados)
- [Laboratório de Física Moderna](#laborat%C3%B3rio-de-f%C3%ADsica-moderna)
- [Programação Linear](#programa%C3%A7%C3%A3o-linear)

## Visão geral

O conteúdo deste repositório inclui:

- projetos de machine learning e visão computacional;
- exercícios e algoritmos de estrutura de dados;
- análises de dados e experimentos de física moderna;
- implementações em linguagem de programação e métodos numéricos.

O objetivo principal é conservar os materiais, códigos e resultados de cada disciplina em um único local para consulta, estudo e evolução do aprendizado.

## Deep Learning

Diretório: [Deep Learning](Deep%20Learning)

Contém projetos relacionados a redes neurais, detecção de objetos e processamento de imagens. Inclui:

- notebooks de estudo e experimentação;
- modelos em PyTorch e Keras;
- arquivos de configuração e pesos de modelos;
- dados e imagens para testes e validação.

### Projetos principais

- Projeto 1: estudo e implementação de YOLO;
- Projeto 2: atenção e mapas de atenção em redes neurais.

## Laboratório de Física Moderna

Diretório: [laboradorio de física moderna](laboradorio%20de%20f%C3%ADsica%20moderna)

Inclui experimentos e análises de física moderna com dados de espectroscopia, efeito fotoelétrico, Franck-Hertz e termoiônico. Há também:

- arquivos de medição em texto;
- notebooks para processamento e análise;

### Conteúdos principais

- Espectroscopia;
- Fotoelétrico;
- Franck-Hertz;
- Termoiônico;
- medições de corpos negros, LEDs e gases.

## Como usar este repositório

1. Navegue pelas pastas por disciplina;
2. Abra os notebooks em ambientes como Jupyter ou VS Code;
3. Execute os scripts conforme as dependências do projeto;
4. Consulte os dados e arquivos auxiliares nas pastas específicas.

## Tecnologias e ferramentas comuns

- Python;
- Jupyter Notebook;
- PyTorch;
- TensorFlow/Keras;
- C;
- Julia (no caso da programação linear);
- análise de dados e visualização científica.
